# GLPI IAM — Identity & Access Governance

GLPI 12 plugin for role-based access governance aligned with ISO/IEC 27001:2022
(A.5.3, A.5.15, A.5.16, A.5.18, A.8.2): position × application-role RBAC matrix
fed from any GLPI inventory item, nominal access register, deviation detection
(segregation of duties, privileged access, orphans, movers), GRC Manager waivers,
owner recertification campaigns and append-only audit notes.

**Status:** design phase. See `docs/superpowers/specs/`.
